# Comment ça fonctionne / How it works

Le PC exécute les jeux. Sunshine capture et transmet l’image ; Moonlight la reçoit sur l’appareil utilisé pour jouer. Monolith X apporte une interface de salon et rassemble bibliothèque, créateurs, vidéos, actualités et retours de joueurs. Il ne remplace pas le protocole de streaming de ces projets.

Le projet associe un serveur Python, une interface web, un client TV adapté pour Tizen et un compagnon Android. Les comptes Steam et Heroic restent gérés par leurs clients ; Monolith X exploite les bibliothèques configurées sur le PC. Certaines fonctions demandent des services Internet ou des outils locaux supplémentaires.

L’installation personnelle et la candidate destinée aux tests sont distinctes. Le code reste privé : cette page décrit l’organisation du projet, pas une API publique stable.

---

The PC runs the games. Sunshine captures and sends the picture; Moonlight receives it on the client. Monolith X adds the living-room interface and brings games, creators, videos, news and player feedback together. It does not replace their streaming protocol.

The project combines a Python server, a web interface, an adapted Tizen client and an Android companion. Steam and Heroic manage their own accounts. Some features require Internet services or additional local tools. Source code remains private; this is an overview, not a stable public API.
