# Retours et confidentialité / Feedback and privacy

Les issues de ce dépôt sont publiques. N’y joins ni mot de passe, ni clé API, ni jeton d’appairage, ni bibliothèque complète ou journal brut contenant des informations personnelles.

Tu peux proposer une idée, signaler une incompréhension dans la présentation ou te proposer pour un test. Si tu as reçu une candidate, indique sa version et les étapes du problème. Le formulaire intégré à l’application peut exporter un diagnostic JSON : lis-le avant de le partager. L’envoi automatique par Supabase n’est pas déployé.

[Écrire un retour](https://github.com/Duperopope/MonolithX/issues/new/choose)

---

Issues in this repository are public. Do not attach passwords, API keys, pairing tokens or unreviewed logs containing personal information.

Ideas, questions about the presentation and offers to test are welcome. If you received a test build, include its version and the steps that reproduce the problem. The application can export feedback as JSON: review it before sharing. Automatic submission through Supabase has not been deployed.
