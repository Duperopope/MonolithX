# Participer / Get involved

Je cherche des personnes qui ont envie d’essayer Monolith X, de discuter de l’expérience ou de partager leur savoir. Tu peux écrire en français, anglais, espagnol, allemand, chinois, portugais ou italien.

[Ouvrir un retour](https://github.com/Duperopope/MonolithX/issues/new/choose). Pour proposer un essai, indique ton système, ton matériel, ton client Moonlight et si Sunshine fonctionne déjà. Pour une idée, explique ce que tu aimerais pouvoir faire et pourquoi. Pas besoin de prétendre avoir testé une version que tu n’as pas reçue.

Ce dépôt est la vitrine du projet. Le code et les paquets de test restent privés pendant la préparation de leur diffusion. Les contributions de code ne sont donc pas encore ouvertes ici. Aucun délai de disponibilité n’est promis.

---

I’m looking for people who want to try Monolith X, talk about the experience or share what they know. Feedback in any of the seven presentation languages is welcome.

[Open an issue](https://github.com/Duperopope/MonolithX/issues/new/choose). If you would like to test it, tell me your OS, hardware, Moonlight client and whether Sunshine already works. If you have an idea, explain what you want to do and why.

This repository is the project showcase. Code and test packages remain private while distribution is being prepared. Code contributions are not open here yet, and there is no promised release date.
